## Cómo usarlos

Consultar el [catálogo orientativo](pantallas.md), el [plan](plan-adaptacion-mockups.md), la [guía visual](../../frontend/DESIGN.md) y la spec de la tarea. Ante diferencias, las reglas de negocio y contratos aprobados determinan el comportamiento. Un enlace de un mockup a una función futura no autoriza implementarla ni mostrarla como disponible.

Trazabilidad: **referencia/página → decisión de adoptar, adaptar o descartar → RN y spec → código/pruebas → commit/PR → integración comprobada**. Pablo autorizó guardar estos archivos en commits atómicos; esto no implica publicación o integración. No hace falta Jira ni una versión independiente para cada documento.

Registrar nuevas fuentes sin borrar ni modificar silenciosamente los originales. Las capturas de QA se adjuntan a la revisión correspondiente; no se guardan todas las páginas renderizadas como recursos de la aplicación.
