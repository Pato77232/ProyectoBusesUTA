Los agentes/comandos de esta carpeta y `opencode.json` se conservan como legado de la herramienta anterior. No son configuración de Codex: sus permisos y comandos no se trasladan automáticamente. Para el trabajo nuevo consultar la guía actual, incluso si se usan estos archivos como referencia. La retirada definitiva del legado puede hacerse en una tarea posterior acordada con el equipo.
